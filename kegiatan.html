Daftar Kegiatan

  • Kegiatan 1: Belajar HTML dan CSS

    Mempelajari struktur pemformatan elemen web dasar menggunakan HTML5 serta teknik *styling* dan tata letak responsif dengan CSS3.

  • Kegiatan 2: Membuat Website Pribadi

    Merancang dan membangun situs portofolio pribadi berbasis tampilan minimalis untuk menampilkan data diri, karya, serta tulisan.

  • Kegiatan 3: Mengikuti Kursus Online

    Menambah wawasan dan mengasah *skill* rekayasa perangkat lunak melalui berbagai materi interaktif di platform pembelajaran online.

  • Kegiatan 4: Membaca Buku Pemrograman

    Mendalami konsep logika, algoritma, serta *best practice* dalam penulisan kode melalui buku-buku literatur teknologi mutakhir.

  • Kegiatan 5: Berpartisipasi dalam Proyek Open Source

    Berkontribusi secara aktif dalam pengembangan proyek terbuka di GitHub untuk melatih kolaborasi tim dan pemahaman alur kerja nyata.
